# Today's Heart Check — User Feedback Questionnaire

> Purpose: 2–4 week user feedback phase before the feature is frozen.
> Every answer is anonymous unless the user volunteers a name. Please collect

## የአሰባሳቢ ማስታወሻ / Collector notes

- Collect 10+ responses minimum before a freeze decision.
- "Which question stayed with you?" answers identify keepers; repeated
  criticism of a specific question makes it a review candidate.
- Do not change the dataset during collection. Record everything first.
